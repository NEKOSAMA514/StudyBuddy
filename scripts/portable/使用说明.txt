StudyBuddy Windows x64 本机验证预览包

此包用于本机验证，尚未完成 Windows 10/11 干净系统验收，也未完成公开分发许可审查。

首次使用
1. 完整解压原始 ZIP 到固定、可写目录（支持中文和空格）。不要在压缩软件中直接运行。
2. 双击“启动.cmd”，首次准备独立 Python 环境可能需要数分钟，保留控制台窗口。
3. 就绪后浏览器自动打开；无法打开时，手动输入控制台显示的 127.0.0.1 地址。
4. 在页面设置中填写自己的 API 凭据。默认 CPU Paraformer 和 RapidOCR 已附带；Whisper 按需下载。
5. 服务仅监听本机，默认 18000；被占用时自动选择 18001—18019，不停止其他服务。
6. 同目录重复启动会打开现有就绪页面；正在准备或退出时请等待原窗口。

正常退出
在启动控制台按一次 Ctrl+C，等待任务、检查点和下载子进程清理完成、窗口返回。
Windows 若在服务完成退出后询问“终止批处理操作吗 / Terminate batch job”，输入 Y 确认即可。
关闭浏览器不会停止服务。避免直接关闭控制台或在任务管理器强制结束。
错误时窗口保留提示；详细日志位于本目录 log，资料与设置位于 data。
控制台可能显示媒体文件路径，分享诊断前请检查私人信息。

目录固定与恢复
首次准备成功后，不要移动或重命名程序目录及其父目录。
发现已经移动时，重新解压原始 ZIP 到新的固定目录，再迁移 data；不要反复修复旧 runtime。
首次准备失败时不会写入成功标记；可在同一目录解决问题后重试。
目录不可写、杀毒软件拦截或解压不完整时，按控制台提示处理。

升级和备份
先在旧窗口正常停机，备份 data 和 log。将新版 ZIP 完整解压到新目录。
将旧 data、需要的日志和可选 Whisper 模型迁入新目录，不覆盖新版 runtime、工具或默认权重。
同机同账户沿用 Windows DPAPI 凭据保护；更换电脑或 Windows 账户后需要重新填写凭据。
不要将私人 data、log 或 .env 回传到源码或发布包。

范围与许可
本包不含个人数据、凭据、测试结果、开发工具或开发目录的配置。
生成笔记会访问用户选择的模型 API；MinerU 解析会上传 PDF。使用前确认相应服务的条款和额度。
项目源码采用 MIT；第三方组件按各自许可提供，见 LICENSE、THIRD_PARTY_NOTICES.txt 和 licenses。
release-manifest.json 记录版本、来源、文件 SHA-256 与公开发布前待办。
本机验证不能代替未安装开发工具的 Windows 10 和 Windows 11 x64 验收。
