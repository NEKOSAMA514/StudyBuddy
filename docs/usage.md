# 安装与使用

本页面向本机使用者：从安装到处理第一份资料，再到阅读、停止恢复和常见问题。接口字段与具体上限统一在 [接口与运行契约](contracts.md) 维护；资料和凭据恢复见 [存储与恢复](storage.md)。

## 安装并启动

使用 Windows x64 便携预览包时，无需执行下面的源码安装步骤。完整解压后双击 `启动.cmd`，等待首次环境准备；默认打开 `127.0.0.1:18000`，占用时自动选择 18000—18019 中的空闲端口。新用户凭据为空，在页面配置。保留控制台，按一次 Ctrl+C 正常退出；关闭浏览器不会停机。目录固定、错误处理及升级见 [便携包说明](portable.md)。预览包不代表已通过干净系统验收。

当前使用 Windows 和 Miniconda。[环境配置](../environment.yml)统一安装 Python 3.12、Node.js 24（含 npm）和 FFmpeg/FFprobe。FFmpeg 选择包含现有视频预览所需 `libx264` 编码器的构建；前端依赖由 `npm ci` 按[锁文件](../frontend/package-lock.json)安装。

在 Miniconda Prompt 中先进入仓库根目录，再依次执行：

```bat
conda env create -f environment.yml
conda activate studybuddy
cd frontend
npm ci
npm run build
cd ..
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

Python 依赖由 [requirements.txt](../backend/requirements.txt)安装，Deno 与 EJS 由已有的 yt-dlp extras 一并安装；语音模型权重仍在设置页按需准备。已经创建且依赖齐全的环境不必重复安装；本机原有 `studyflow` 环境可继续使用，将激活命令改为实际环境名。旧环境需要同步依赖时，在仓库根目录执行 `conda env update -n 实际环境名 -f environment.yml`。项目另有 [FFmpeg 安装工具](../scripts/install-ffmpeg.ps1)，可使用本机缓存的压缩包安装到 `tools/ffmpeg/bin`。

启动后打开 [工作台](http://localhost:18000)。终端应保持运行；退出时按 Ctrl+C，等待后台操作完成清理后再关闭窗口。脚本按仓库所在位置确定资料目录，不要求项目位于某个固定盘符。

日常启动只需激活已有环境并运行启动脚本。更新前端后重新构建再刷新正式页面；后端代码变化需要重新加载服务。开发方式见 [开发与测试](development.md)。

新版第一次启动可能迁移旧凭据文件；迁移必须由原 Windows 账户执行，失败会停止启动。先阅读 [凭据与迁移](storage.md#私人配置与凭据)，不要删除配置或用残留临时文件替换主配置。

## 完成首次设置

从侧栏打开“设置”：

| 类别 | 要做的事 |
|---|---|
| API设置 | 添加 API 地址、密钥和模型 ID，保存并启用一组连接 |
| 语音识别模型 | 根据材料语言选择 Paraformer 或 faster-whisper，准备模型文件后保存 |
| OCR 模型 | 检查 RapidOCR 文件和运行组件状态，保存选择；内置权重由程序按需准备 |
| 笔记风格 | 设置默认简洁／详尽风格，以及可选的笔记补充要求 |
| 网络代理 | 按需要设置后续视频解析与下载使用的代理 |
| 登录凭证管理 | 按需要扫码登录或退出 B 站 |

API 地址是兼容 Chat Completions 的基础地址。模型 ID 可手填，也可用当前地址和密钥读取列表；读取列表无需先保存，也不等于模型生成能力已验证。“测试连接”会实际发送模型请求，保存配置不会调用模型。

编辑已有连接时，密钥留空表示保留；清除密钥使用专门操作。修改 API 地址后需重新提供对应密钥。运行中和恢复中的任务使用原执行快照，具体规则见 [任务配置](contracts.md#配置与执行快照)。

API设置中的 MinerU Token 与模型 API 密钥分别保存。PDF 不填 Token 可选轻量解析，保存 Token 后新导入默认使用精准解析，也可明确选择本地方式。代理设置只作用于视频解析、下载等对应网络操作，不改变模型 API 的连接方式。

## 处理视频

1. 在“总结分析”选择或拖入一个视频；也可以粘贴链接、解析画质并下载，再导入生成。
2. 上传或下载本身不开始生成。打开视频后点击“开始处理”，确认本次 API、笔记风格、语音和 OCR 选择。
3. 任务进入共享队列。页面显示实际步骤和动态；已有结果可在处理期间阅读。
4. 完成后阅读章节，通过时间入口回看视频，通过依据入口核对语音或画面文字。

B 站支持 BV 号、普通链接、短链接及含单个链接的分享文案；多 P 视频每次选择一 P，并为该 P 重新确认画质。未登录时可扫码，也可暂不登录继续。平台字幕可用时优先采用；不可用时按任务规则回退本地语音识别。其他站点是否能下载取决于下载器和站点当时的可访问状态。

浏览器不能直接播放某些原件时，程序按需准备兼容播放副本；原件仍保留。点击笔记时间戳只定位播放器，使用“回到笔记”返回阅读位置。

## 处理文档

选择 PDF、DOCX、PPTX、XLSX、CSV、TXT 或 `.md` 后，网页先保存原文件并打开详情。取消后续确认不会删除原件，刷新后仍可继续处理。

点击“开始处理”后确认本次配置。只有 PDF 提供 MinerU／本地选择；其他格式在本地提取。后台提取失败不会自动改成另一种解析方式，需根据提示明确重试或重新选择。提取期间不能删除资料。

材料保存后即可查看“提取内容”，笔记任务可能随后才创建并排队。预检超限或生成失败不影响已经保存的材料；已有材料重新生成笔记会复用提取内容。若要更换解析方式或 OCR 重新提取，应重新导入原文件。

| 格式 | 如何理解来源与提取结果 |
|---|---|
| PDF | 本地按页读取文本和实际绘制图片；MinerU 轻量按批次、精准按可核验页码组织材料。复杂公式与版面仍需核对 |
| DOCX | 保留正文块顺序和表格、内嵌图片；来源是正文块，不推算 Word 页码 |
| PPTX | 保留幻灯片位置、文字、基本表格、备注、内嵌图片及可读分类图表数据；散点、气泡或组合图表等记录具体警告 |
| XLSX | 保留工作表、行号和公式原文；不计算公式，不读取图表 |
| CSV | 按逻辑记录组织，带引号的换行记录不等同于物理文件行 |
| TXT／Markdown | 按原行号分块；跨块代码围栏或表格可能无法完整预览 |

图片 OCR 未检出文字与识别失败会分别提示，警告不作为生成材料。MinerU 合并表格支持常见正整数跨行／跨列占位，无法可靠转换的结构明确报错。本地提取不承诺还原任意扫描页、SmartArt、复杂公式或阅读顺序。

PDF 本地读取使用 pypdfium2 与 pypdf；加密 PDF（包括用户密码为空的加密文件）会明确拒绝，请先在原工具中解除加密后上传。更新依赖后，已保存材料、笔记和兼容的后台提取进度继续复用，不会自动重跑 OCR。具体恢复规则见 [存储说明](storage.md#缓存检查点与版本)。

“提取内容”默认折叠，展开后可翻组或按内容块定位。文档笔记中的来源入口可跳到对应材料起点；来源范围描述的是原文支持位置，不代表复原了原页面版式。

## 阅读、版本与重点

简洁风格介绍每部分的主题和用途；详尽风格展开知识、解释和代码。新默认风格仅影响后续任务，已有笔记不会自动改写。

完成的片段可先阅读、导出；这类草稿不代表整份任务已经成功。详情保留最近两份完整成功笔记供切换，阅读旧版本不会重启生成，也不会改变当前任务。

完整成功笔记可标记重点：详尽风格按章节，简洁风格按实际二级小标题。标记属于当前版本，新版本不继承；被淘汰版本的标记一并清理。标记不改正文或导出内容。

笔记中心搜索每份资料最新的完整成功笔记，多个空白分隔关键词需在同一搜索单元内全部出现。它不是原件全文、历史版本或语义搜索。“我的重点”可回看仍保留版本的标记；查询、页码和定位信息保存在 URL 中。

## 停止、重试与页面断线

- 笔记任务排队时可停止；执行中停止需等待清理完成，再继续。失败或中断使用重试入口。
- 继续和重试沿用原任务、执行配置和可兼容的成功检查点；重新生成会创建新任务。
- 关闭或刷新页面不会停止后台处理。服务重启后，笔记任务的执行中状态转为中断，需手动恢复；未完成的后台文档提取会在启动时尝试接续。
- 显示“操作已接受，正在同步状态”表示提交已成功，正在确认完整任务；不要因此重复提交。
- 读取失败可用“重新读取”恢复，已有正文和列表尽量保留。错误编号及日志位置用于排查；页面连接提示不等于后台任务已经失败。

## 常见问题

| 现象 | 先检查什么 |
|---|---|
| 无法连接本地服务 | 后端终端是否仍运行、端口是否正确；开发页也需要可访问的后端 |
| 识别组件或模型未就绪 | 当前激活环境、设置中的型号状态及模型文件；文件存在不一定代表运行组件可用 |
| 修改后正式页面没有变化 | 是否重新构建前端并刷新；正式页面不读取开发服务器的源文件 |
| 生成被预检拒绝 | 查看资格与预算提示，拆分材料或调整允许的输入配置，不把预检失败当成提取丢失 |
| 恢复提示连接地址或生成规则已变化 | 恢复原 API 地址／配置；不兼容的生成规则需要重新生成，已完成笔记仍可读 |
| 启动时私人设置无法解密 | 保留文件与错误日志，按 [存储恢复说明](storage.md#启动迁移与失败恢复)检查账户及备份 |

排查时先保留最后成功资料，避免把清缓存、删除配置或重复上传作为默认修复。错误结构与日志语义见 [接口与运行契约](contracts.md#错误与诊断)。
